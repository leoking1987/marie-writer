# Marie Writing DNA

## 证据状态

当前版本是 v1 基线：依据历史 Top5 完整口播、本人发言证据、当前内容结构手册和声音规则整理。它足以约束写作，但不等同于 20 篇以上的完整 DNA 蒸馏。后续获得至少 20 篇完整脚本后，更新本文件并移除“种子版”标记。

## L1 语言 DNA

- 用具体场景、动作、价格、空间和真实反应进入主题。
- 感受要附着在对象和细节上，不以“太、真的、绝美”堆强度。
- 判断可以锋利，但要承认缺点、代价和适用条件。
- 句子长短跟着观察和判断变化，不把每段切成短视频金句。
- Marie 的第一人称只对应真实经历；团队动作说“我们／团队”。

## L2 结构 DNA

- 豪宅/社区实拍：场景入口 → 第一感受 → 关键细节 → 真实缺点 → 适合谁。
- 卖房案例：结果 → 困难 → 动作 → 可验证结果 → 方法边界。
- 市场分析：结论 → 分化 → 原因 → 买卖双方行动。
- 决策科普：两难 → 改变选择的关键变量 → 代价 → 条件式建议。
- 创业成长：具体瞬间 → 误判/冲突 → 代价 → 认知转折 → 今天的方法。

## L3 选题判断

优先选择真实处境里能看见、能比较、能改变判断的事。豪宅和环境提供入口，真正内容仍是选择、代价和生活变化。拒绝只靠名人、价格和情绪成立的题目。

## L4 素材策略

- 真实房源、现场观察、空间细节和可核验数据优先。
- 客户经历必须匿名、准确且有公开边界。
- 市场数字说明来源和口径。
- 不用虚构人物、对白、心理和邻居故事补细节。

## L5 认知框架

Marie 通过具体场景看见人如何做选择，再用审美、空间、家庭关系、时间与资产条件拆解取舍。观点来自亲眼看到、比较过和真正付出代价的细节；不是中性百科摘要，也不把复杂问题压成一句口号。

## L6 视觉 DNA

- 看房以真实空间、动线、材质、采光和缺陷为核心。
- 人物出现时保留自然动作与观察，不安排表演式摆拍。
- 字卡和数据图负责补充信息，不抢占人的处境。
- B-roll 要有主体动作、空间变化和语义，不用静态豪宅卡片充当包装。

## 写前读取

1. 本文件。
2. 当前题材最接近的 2–5 篇 Marie 本人原文。
3. 当期事实、真实案例边界和平台语域。

## 更新协议

取得至少 20 篇完整内容后，按六个维度重新统计并更新：语言、结构、选题、素材、认知、视觉。每条结论保留至少两条来源证据，不把采访对象或 Kevin 的发言并入 Marie 的 DNA。
