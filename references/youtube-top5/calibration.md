# Marie 原文对照与改写

## 使用参考组

先读 [样本索引](index.md)。首次使用本技能完整读取五篇全文；同一会话已读过时，回到当前题材最接近的全文。结合 [本人发言与观察](voice-evidence.md) 确认归属，再选锚点。采访对象讲得长、播放高，也不能成为 Marie 的语言样本。

写前选至少两段经确认的 Marie 本人连续发言，覆盖当前稿需要的功能，例如现场观察、追问、空间评价、科普解释或收口。记录视频 ID、段落起句和适用原因。无法确认是谁说的段落只能帮助理解内容，不能用于模仿。

这些样本跨题材、跨年份，提供她怎样说话的证据。高播放无法证明句式带来了流量，也不要求新内容复刻街头采访的负面主题。Marie 的硅谷高端房产专业定位、事实和隐私边界继续生效。

## 写后必须实际对照

先按根目录 SKILL.md 的观众得失规则复核选题、开场与关键句，再对照本人表达。原文锚点校准声音，不能代替本题的利益关系；平稳解说样本不能成为删除有依据的情绪或生活后果的理由。只有措辞像本人、却说不清观众获得或失去什么，仍须回到切口与证据重写。

对照用来校准本人的观察、反应与语气，不把某一篇旧稿的情绪强度当作上限。按 `SKILL.md` 的情绪表达要求，检查喜欢、惋惜、心疼、好笑或释然是否由具体细节承接；有当前材料支持的反应应保留，不为了显得专业全部改成中性评价。

逐段把生成文字与适用的本人原文并排读：

| 看什么 | 需要比较的实际内容 |
| --- | --- |
| 观察从哪里开始 | 原文看到什么、指向什么、再做什么评价；新稿是否只说“现实、成本、认知”等概念 |
| 句子怎样往下走 | 原文怎样接原因、补充、取舍和反应；新稿是否反复总结、制造碎句或抽象对照 |
| 问题怎样出现 | 追问是否顺着已说出的事实；是否以连续设问拖住答案 |
| 主观判断怎样表达 | 原文怎样说喜欢、担忧、意外和改观；新稿是否硬造金句、替别人安排心理变化 |
| 专业怎样落地 | 是否解释空间、功能、费用、限制或选择的实际影响；是否只堆“高级、清醒、锋利” |
| 怎样结束 | 是否把这件事讲完，再给相关下一步；是否忽然进入成功学升华或业绩播报 |

每个主要内容段落都要有适用的本人原文依据，可重复使用同一锚点。短视频从原文中保留展开方法并压缩信息，不靠口头禅或“你很忙，不代表……”之类句式假装像本人。独白稿不复刻搭档对话的抢接和重复。

五篇没有直接覆盖某种体裁时，借用可确认的观察、解释和判断方法，注明没有同体裁样本。尤其创业复盘不能把餐馆老板的经历转给 Marie；需要她的真实材料才能写第一人称。

## 改写闭环

内部记录至少保留：`成稿段落 → 本人原文 ID 与起句 → 具体偏差 → 改后段落 → 复核结果`。

发现偏差后实际重写该段，再回到同一原文复核；整篇朗读检查衔接。只有点评、打分或“已 Marie 化”的声明不算完成。关键段落仍缺本人依据或事实材料时，说明缺口并保留待补状态。

后续若再做口语化、压缩时长或套其他结构，交付前对最终版本重新对照；不能让中间稿通过后，最终稿又换成另一位创作者的口吻。

检查“不是 X，而是 Y”“X 不代表 Y”“X 不等于 Y”是否新增事实、原因或选择标准。没有新增内容就改成具体发生了什么、为什么、有什么后果。真实必要的否定和条件可以留。反常识须有确实存在的预期、经核实的相反结果和解释机制；普通常识提醒按普通提醒写。

原文的旧市场数据、合规风险、服务名额、采访对象的措辞、错词和无意义重复都不能复制。对照的是本人表达方法，始终服务当前事实、用户指定风格和高端房产品牌定位。

默认只交成稿；对照记录留在内部。用户要求审核或修改依据时，展示原文依据、具体偏差及改后段落。
