## 1. 样本结论

提供的近一年 Top 10 长视频样本显示：

- 豪宅与社区实拍是最强流量入口；高价、名城、名人、老房或硬伤提供矛盾。
- 卖房案例以“困难—动作—结果”建立信任，具体时间、投入和相对结果比泛泛晒成交更有说服力。
- 市场分析表现最好时讲“哪里强、哪里弱、为什么分化”，而不是只喊涨跌。
- 标题普遍含地点、价格、时长、结果、收入门槛、名人或反常识命题。
- 视频常由 Marie 与 Kevin 对谈，用追问、补充和轻微分歧维持节奏。

这些是特定时间窗口的内容证据，不等于永久流量定律。选题前仍要结合最新市场与平台反馈。

## 2. 标题与开头

### 标题公式

- `地点 + 具体价格/门槛 + 强问题`：Palo Alto 650 万新房，最值钱的真是装修吗？
- `困难 + 动作 + 结果`：有硬伤的 Townhouse，我们为什么只改了这 3 处？
- `常见习惯 + 反常识结论`：卖房前先刷 Zillow？最容易错的恰恰是这一步。
- `人群 + 决策`：年薪 30 万的湾区家庭，应该先买还是先卖？
- `名人/趋势 + 本地价值`：AI 新贵进场后，Atherton 真正变贵的是什么？

标题必须兑现。不要为了点击使用正文无法证明的“最贵、第一、暴涨、绝不能”。

### 开头公式

在前 15—30 秒完成：

1. 抛出具体事实或眼前场景。
2. 给出反差、风险或争议。
3. 承诺本条会给出的判断。

示例骨架：

> 这套房开价 `[价格]`，但我进门第一眼看的不是厨房，而是 `[硬伤/稀缺点]`。今天我带你看三个细节，最后告诉你它到底适合谁。

## 3. 五类内容骨架

### A. 豪宅或社区实拍

1. 具体地点、价格、面积或名人/历史入口。
2. Marie 的第一感受，用一个可见细节证明。
3. 解释 3 个核心卖点：设计、土地/地段、生活方式或稀缺性。
4. 指出至少 1 个真实缺点、维护成本或适配限制。
5. 给出“适合谁 / 不适合谁 / 我会不会买”的判断。
6. 以看房、评论或咨询中的一个动作收口。

把参数嵌进走动与观察，不要把 Room Tour 写成配置表。

### B. 卖房或客户案例复盘

1. 先说结果，但保留问题：“6 天全现金成交，但这套房有三个硬伤。”
2. 交代客户目标与隐私安全的背景。
3. 逐条说明困难：市场、房屋、时间或资金。
4. 对应说明动作：时机、定价、整理、内容、谈判。
5. 给出可验证结果和限制，避免暗示人人可复制。
6. 总结 2—3 个决策原则，并引导同类需求咨询。

### C. 市场与数据分析

1. 先给一句带边界的结论和数据日期。
2. 不只给平均数；拆分地区、房型、价位或买卖方。
3. 每组数据解释“为什么”和“这对谁意味着什么”。
4. 加入近期真实业务观察，但区分样本观察与整体统计。
5. 分别给买家和卖家一个行动建议。
6. 说明下一次需要观察的指标或时间点。

数字密集时，用“翻译成大白话”把指标变成生活决策。

### D. 决策科普与工具拆解

1. 点名常见误区或高成本错误。
2. 承认这个做法为什么看起来合理。
3. 拆出 3 个盲区或关键变量。
4. 用一个具体房产/家庭场景解释差异。
5. 给出替代流程，而不是只批评。
6. CTA 对应一个低门槛下一步，如评估、清单或咨询。

### E. 创业、成长与女性议题

1. 从一个具体瞬间开始，不从人生大道理开始。
2. 写当时的想象和真实发生的冲突。
3. 写代价：时间、钱、关系、体力或自我怀疑。
4. 写认知转折，不美化过程。
5. 落到今天做选择的方法。
6. 结尾留一个有力量但不喊口号的判断。

这类内容重点是“她怎么长出来的”，不是罗列今天的成绩。

## 4. 平台适配

- YouTube 长视频：默认 6—12 分钟；每 60—90 秒出现一次新问题、反差、数据或空间变化；允许 Marie/Kevin 对谈。
- 短视频：默认 45—90 秒；只讲一个冲突和一个结论，删除完整背景史。
- 小红书：标题具体；开头两三行兑现结果；正文用短段落和少量小标题，保留体验与避坑判断。
- 朋友圈：默认 150—350 字；从当日现场或感受切入，结尾轻，不做完整课程式结构。
- 社交媒体长文：先故事后观点；小标题用于转折，不把每句话拆成单独一行。

若用户给出明确时长、字数或平台规范，以用户要求为准。

## 5. CTA 与成稿检查

### 轻 CTA

- 看房实拍：邀请评论“会不会买”或预约看房，二选一。
- 案例复盘：邀请有同类卖房/换房问题的人做一对一评估。
- 市场分析：邀请提供预算、区域和时间线以获得更具体判断。
- 成长内容：邀请分享类似经历，不强行转房产业务。

只有真实存在的名额、服务和资源才能写。不要默认制造“每周仅两个名额”等稀缺话术。

### 最终检查

- 标题里的数字、地点、人物和结果都能在正文中证明。
- 开头不是寒暄，30 秒内出现内容承诺。
- 至少有一个具体场景或证据。
- 优点、缺点和适配判断同时存在。
- 没有把新闻写成亲历，没有泄露客户身份。
- 专业术语都被翻译成观众能行动的含义。
- 删除重复、空洞形容词、假金句和无意义口头禅。
- CTA 与本条内容一致，且只有一个主动作。
